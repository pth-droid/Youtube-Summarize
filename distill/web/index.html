        Your library is one SQLite file and its folders. It needs no separate server.

        Paste a full folder path, or browse. Choose a new or empty folder: saved pages, source files and preferences are copied there, and the current folder stays as a backup. Finish or cancel processing first. The choice is remembered for the next launch.
