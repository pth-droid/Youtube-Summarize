# Select a visual grammar

Choose by information structure. Concept map: concepts connected by labelled relationships. Causal graph: supported or explicitly inferred causes. Process: ordered mechanism or procedure. Argument map: claim, supporting evidence, objection. Timeline: source development in time. Hierarchy: levels, parts, prerequisites. Comparison: competing choices with shared dimensions.

Usually select two or three complementary views when useful. A small source may need one. Avoid repeating the same nodes in several decorative diagrams. Use at most twelve visible nodes per diagram and keep the main overview to eight. Important caveats stay beside the relevant node.

For process views, order nodes using source-supported `precedes` links. For comparison, put actual competing approaches next to each other, not unrelated facts. A timeline uses real source sections and timestamps; imported untimed text uses source order instead. Select relation IDs only when both endpoints are included.

The presentation artifact contains IDs, view type, a reader question, title, and rationale. It references semantic records and does not rewrite their conclusions. The renderer provides keyboard and touch controls and a readable narrow-screen alternative to large diagrams.
