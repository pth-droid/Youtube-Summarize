# Explore the mental model

Start with orientation and major ideas. Selecting an idea opens its explanation, labelled evidence status, caveats, relationships, saved deeper units, and original source context. Allow focus on one idea and related nodes. Provide a clear return to overview.

`Dig deeper` reveals saved children; it does not promise a live model response. `Evidence` shows original-language quotations and nearby source snippets. A timestamp opens the corresponding YouTube position; never generate a false timestamp for untimed text.

Keep critical caveats visible. Use actual buttons and native disclosures with visible keyboard focus. The same content must be readable on phones without hover or smaller text. Complete source text remains searchable. Offline exports include all assets and saved interactions; online video playback is external.
