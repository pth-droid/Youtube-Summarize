# Teaching depth and language

Beginner: define original technical terms, make prerequisites visible, use one supported concrete example. Balanced: explain the important mechanisms and tradeoffs, preserve technical terms, save further evidence and examples under deeper branches. Advanced: retain domain detail and caveats, reduce basic definitions, keep prerequisites accessible.

Follow the selected learning goal without discarding the rest of the source. Default output Vietnamese (`vi`), with original technical terminology in parentheses or inline where useful. English (`en`) is an alternative. Source quotations remain original. Added examples and general background must be explicitly marked as background rather than attributed to the speaker.

Use clear short explanations. Visuals should communicate relationships and mechanism; avoid a long article padded by diagrams. The reader should be able to explain the big picture and find why, how, and where the source supports it.
